# Company Interview Profiles

## Toss (비바리퍼블리카)

### Tech Stack
- Kotlin + Spring Boot (주력)
- Java (레거시)
- MySQL, Redis, Kafka
- Kubernetes, AWS

### Interview Process
1. 서류 → 2. 코딩테스트 (프로그래머스) → 3. 1차 기술면접 → 4. 2차 기술면접 → 5. 컬처핏

### Interview Focus
| Round | Format | Key Topics |
|-------|--------|-----------|
| 코딩테스트 | 프로그래머스 2-3문제, 2시간 | 구현, DP, 그래프 |
| 1차 기술 | 1:1 또는 2:1, 60분 | 프로젝트 딥다이브, 기술 선택 근거 |
| 2차 기술 | 시스템 디자인 + CS | 대규모 트래픽, 금융 안정성 |
| 컬처핏 | 행동 면접 | "왜?", 실패 경험, 성장 |

### Key Signals
- "왜 그 기술을 선택했는가" 근거 중시
- 장애 대응 경험, 트러블슈팅 프로세스
- 금융 도메인 트랜잭션 정합성
- 코드 품질 + 테스트 문화

## Mock Interview Session Structure

### Coding Interview (30-45분)
1. 문제 제시
2. 사용자 clarifying questions
3. 접근법 설명 → 피드백
4. 코딩 (Java 기준, Kotlin 선택 가능)
5. 테스트 케이스 검증
6. 최적화 논의
7. 평가 (Hire / Lean Hire / Lean No Hire / No Hire)

### System Design Interview (45-60분)
1. 문제 제시
2. 요구사항 정리
3. High-level design
4. Deep dive (면접관 역할로 추가 질문)
5. 평가 + 피드백

### Behavioral Interview (30분)
1. 질문 제시 (STAR 포맷 유도)
2. 사용자 답변
3. Follow-up 질문 (실제 면접처럼)
4. 피드백 + 개선점
