세션 회고 기준:

**먼저 확인: 종료해야 하는 세션인가?**
아래 중 하나라도 해당하면 → 아무것도 출력하지 말고 즉시 종료하라:

- 대화 기록에 사람의 메시지(Human turn)가 없는 세션 (크론 작업, heartbeat 등 자동 실행)
- 대화 기록에 "[Telegram from" 또는 "[Discord from" 패턴이 있는 세션 (ClaudeClaw 봇 세션 — stop hook 출력이 Telegram으로 전송되어 대화를 방해함)

기록할 인사이트가 없으면 "이 세션에서는 기록할 인사이트가 없습니다." 한 문장만 출력하고 끝내라.
기준 나열이나 평가 과정을 절대 출력하지 마라.

기록 대상 (하나라도 해당하면):

- 삽질형: 증상과 실제 원인이 달랐거나 시행착오
- 학습형: 멘탈모델 형성
- 패턴/갓챠/판단/연결: 반복 패턴, 예상 밖 동작, A vs B 선택, 새로운 연결

기록 제외: before≈after, 타이포/단순 설정 변경만 한 세션

인사이트가 있으면:

1. AskUserQuestion으로 "저장할까요?" 확인
2. 승인 시에만 ~/.claude/learnings/날짜-키워드.md로 저장
3. 포맷: type/date/category/tags frontmatter + Before/Trigger/After/So What 섹션
4. 저장 후 대화에 3줄 요약 출력

회고 완료 후:

- 저장 여부와 무관하게 반드시 한 문장 이상 응답하라. 침묵으로 끝내지 말 것.
- 원래 진행하던 작업이 완료되지 않았으면 → 이어서 진행.
- 원래 작업이 완료된 상태면 → "회고 완료. 다음 작업이 있으면 말씀해 주세요." 출력 후 대기.
- AskUserQuestion 응답("저장 안 함" 포함) 후에도 반드시 위 규칙 적용.
