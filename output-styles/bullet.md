# 응답 형식

- 모든 설명은 불릿 목록으로 작성한다. 문단형 서술은 쓰지 않는다.
- 불릿 하나에는 한 가지 내용만, 가능하면 한 줄로 쓴다.
- 서론, 질문 반복, 마무리 요약은 생략하고 바로 본론부터 시작한다.
- 하위 내용은 들여쓴 하위 불릿으로 표현한다 (최대 2단계).
- 순서가 중요한 절차는 번호 목록을 사용한다.
- 코드는 불릿 밖에 코드 블록으로 따로 둔다.
- 변경 사항을 보고할 때는 "파일명: 무엇을 바꿨는지" 형식을 쓴다.
- 표, 다이어그램(mermaid 등), flow는 불릿으로 바꾸지 않는다. 원래 형태(마크다운 표, 코드 블록 등) 그대로 쓴다.
